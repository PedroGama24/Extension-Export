# Política de Privacidade — Exportação Automática de CSV

**Última atualização:** 16 de junho de 2025

## Resumo

Esta extensão do Chrome **não coleta, armazena nem transmite dados pessoais** para servidores externos do desenvolvedor.

## Dados processados

A extensão funciona **localmente no seu navegador** e apenas:

- Interage com páginas do domínio `alloha.fs.ocs.oraclecloud.com` (Oracle Cloud), quando você inicia uma exportação.
- Gera e baixa arquivos CSV no seu computador, usando a API de downloads do Chrome.

Os dados exportados são obtidos **diretamente do Oracle Cloud**, com a sua sessão já autenticada no navegador. O desenvolvedor não tem acesso a esses dados.

## Permissões utilizadas

| Permissão | Motivo |
|-----------|--------|
| `activeTab` | Acessar a aba ativa do Oracle Cloud durante a exportação |
| `scripting` | Executar o script de exportação na página autorizada |
| `downloads` | Salvar o arquivo CSV final no seu computador |
| `host_permissions` (Oracle Cloud) | Permitir que a extensão funcione apenas no sistema Alloha |

## Compartilhamento de dados

Não vendemos, alugamos nem compartilhamos dados com terceiros. Nenhuma informação é enviada a servidores do desenvolvedor.
